# عمرة و حج الجزائر — موقع العروض

موقع React + TypeScript + Tailwind CSS، باللغة العربية (RTL)، بثلاث صفحات.

## التشغيل

```bash
npm install     # مرة واحدة فقط
npm run dev     # للتطوير  → http://localhost:5173
npm run build   # لإنتاج نسخة جاهزة للنشر في مجلد dist/
npm run preview # لمعاينة نسخة الإنتاج
```

## هيكل الصفحات

| الصفحة | الرابط | المحتوى |
|---|---|---|
| الرئيسية | `/` | هيرو كبير + شبكة 3 بطاقات للمطارات + الفوتر |
| المطار | `/airport/annaba` | هيرو مع `الرئيسية › اسم المطار` + شبكة تواريخ الإقلاع + الفوتر |
| العرض | `/airport/annaba/offer/annaba-ramadan-15` | هيرو مع `الرئيسية › المطار › اسم العرض` + صورة كبيرة + تفاصيل مطوّلة + زر «احجز الآن» + الفوتر |

الموقع يستعمل `HashRouter`، أي أن الروابط تكون بالشكل `.../#/airport/annaba`.
الفائدة: يشتغل على أي استضافة عادية بدون أي إعدادات إضافية.

## تعديل المحتوى — ملفان فقط

كل النصوص والعروض والتواريخ موجودة في:

### `src/data/site.json`
- `name` / `tagline` — اسم الوكالة
- `heroTitle` / `heroSubtitle` / `heroImage` — هيرو الصفحة الرئيسية
- `whatsapp` — **رقم الواتساب بالصيغة الدولية بدون `+` وبدون فراغات**، مثال: `213555123456`
- `whatsappMessage` — الرسالة المكتوبة مسبقا التي تفتح مع المحادثة
- `facebook` — رابط الصفحة
- `footer.columns` — أعمدة الفوتر وروابطها

> أي رابط في الفوتر تركت فيه `"url": ""` فارغا سيعيد الزائر إلى الصفحة الرئيسية.
> بمجرد ما تضع رابطا حقيقيا مكانه سيفتح الرابط في تبويب جديد تلقائيا.

### `src/data/airports.json`
مصفوفة المطارات. كل مطار يحتوي على:

```jsonc
{
  "id": "annaba",                  // يظهر في الرابط، بالحروف اللاتينية وبدون فراغات
  "name": "مطار عنابة الدولي",
  "city": "عنابة، الجزائر",
  "shortText": "النص القصير في البطاقة",
  "image": "/images/airport-annaba.svg",
  "intro": "فقرة تظهر فوق شبكة التواريخ",
  "offers": [ ... ]
}
```

وكل عرض داخل `offers`:

```jsonc
{
  "id": "annaba-ramadan-15",
  "name": "عمرة رمضان — 15 يوم",
  "date": "2026-03-05",            // للترتيب فقط (YYYY-MM-DD)
  "dateLabel": "05 مارس 2026",     // التاريخ كما يظهر للزائر
  "duration": "15 يوم",
  "price": "185.000 دج",
  "seats": "المقاعد محدودة",
  "hotel": "فندق 4 نجوم — 300م عن الحرم",
  "image": "/images/offer-1.svg",
  "summary": "سطر أو سطران يظهران في البطاقة وتحت العنوان",
  "sections": [
    { "title": "عنوان الفقرة", "paragraphs": ["نص...", "نص..."] },
    { "title": "ما الذي يشمله السعر؟", "list": ["نقطة", "نقطة"] }
  ]
}
```

- `paragraphs` → فقرات نصية عادية (المقال الطويل)
- `list` → قائمة نقاط مع علامة ✓ خضراء
- يمكن إضافة أي عدد من المطارات أو العروض أو الفقرات، والموقع يتكيف تلقائيا.

## الصور

الصور الحالية في `public/images/` هي **صور مؤقتة** (ملفات SVG بسيطة مكتوب عليها اسمها).
استبدلها بصورك الحقيقية:

1. ضع الصورة في `public/images/` (مثال `hero.jpg`)
2. غيّر المسار في ملف JSON إلى `/images/hero.jpg`

المقاسات المنصوح بها:
- هيرو الرئيسية وصور العروض: عرضية، حوالي **1600×900**
- صور بطاقات المطارات: طولية، حوالي **800×1000**

## الألوان

ثلاثة ألوان فقط، معرّفة في أعلى `src/index.css`:

```css
--color-brand: #0b6e4f;   /* الأخضر الأساسي */
--color-sand:  #f6f4ef;   /* خلفية الموقع */
--color-ink:   #1c1c1c;   /* النصوص والفوتر والهيرو */
```

غيّر القيمة هنا فقط ويتغير الموقع كله.

## النشر

```bash
npm run build
```

ثم ارفع محتوى مجلد `dist/` إلى أي استضافة (Netlify، Vercel، أو استضافة عادية عبر FTP).
