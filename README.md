# عمرة و حج الجزائر — موقع العروض

موقع React + TypeScript + Tailwind CSS، باللغة العربية (RTL)، بثلاث صفحات.

## التشغيل

```bash
npm install     # مرة واحدة فقط
npm run dev     # للتطوير  → http://localhost:5173
npm run build   # لإنتاج نسخة جاهزة للنشر في مجلد dist/
npm run preview # لمعاينة نسخة الإنتاج
```

## هيكل الصفحات

| الصفحة | الرابط | المحتوى |
|---|---|---|
| الرئيسية | `/` | هيرو كبير + شبكة 3 بطاقات للمطارات + الفوتر |
| المطار | `/airport/annaba` | هيرو مع `الرئيسية › اسم المطار` + شبكة تواريخ الإقلاع + الفوتر |
| العرض | `/airport/annaba/offer/28-septembre` | هيرو مع `الرئيسية › المطار › اسم العرض` + صورة كبيرة + تفاصيل العرض + زر «احجز الآن» + الفوتر |

الموقع يستعمل `HashRouter`، أي أن الروابط تكون بالشكل `.../#/airport/annaba`.
الفائدة: يشتغل على أي استضافة عادية بدون أي إعدادات إضافية.

## تعديل المحتوى — ملفان فقط

### `src/data/site.json`
- `heroTitle` / `heroSubtitle` / `heroImage` — هيرو الصفحة الرئيسية
- `whatsapp` — **الرقم بالصيغة الدولية بدون `+` وبدون فراغات** (حاليا `213560659291`)
- `whatsappDisplay` — الرقم كما يظهر للزائر تحت زر الحجز
- `whatsappMessage` — الرسالة المكتوبة مسبقا التي تفتح مع المحادثة
- `facebook` — رابط الصفحة
- `footer.columns` — أعمدة الفوتر وروابطها

> أي رابط في الفوتر تركت فيه `"url": ""` فارغا سيعيد الزائر إلى الصفحة الرئيسية.
> بمجرد ما تضع رابطا حقيقيا مكانه سيفتح الرابط في تبويب جديد تلقائيا.

### `src/data/airports.json`

مصفوفة المطارات. **تفاصيل العرض مكتوبة مرة واحدة لكل مطار**، وكل تواريخ ذلك
المطار تستعمل نفس التفاصيل — يعني إذا غيّرت سعرا يتغير في كل التواريخ دفعة واحدة.

```jsonc
{
  "id": "annaba",                       // يظهر في الرابط، حروف لاتينية بدون فراغات
  "name": "مطار عنابة",
  "city": "عنابة",
  "shortText": "النص القصير في بطاقة الصفحة الرئيسية",
  "image": "/images/annaba.jpeg",       // صورة البطاقة + صورة صفحة العرض
  "intro": "فقرة تظهر فوق شبكة التواريخ",

  // معلومات مشتركة تظهر في البطاقات وفي شريط المعلومات السريعة
  "duration": "15 يوم",
  "price": "ابتداءً من 2850 دينار تونسي",
  "stay": "3 أيام في المدينة و11 ليلة في مكة",
  "summary": "سطر يظهر في البطاقة وتحت عنوان صفحة العرض",

  "sections": [ /* تفاصيل العرض — انظر تحت */ ],
  "dates":    [ /* تواريخ الإقلاع — انظر تحت */ ]
}
```

#### `sections` — تفاصيل العرض (صفحة العرض فقط)

**هذا هو المكان الوحيد الذي توضع فيه الإيموجي.** كل عنصر يمكن أن يحتوي على
`paragraphs` و/أو `list` و/أو `prices`:

```jsonc
{
  "title": "🌟 العرض الاقتصادي",
  "paragraphs": ["💰 ابتداءً من 2850 دينار تونسي", "🏨 الإقامة: ..."],
  "list": ["✅ التأشيرة", "✅ النقل"],
  "prices": [
    { "room": "غرفة خماسية", "price": "2850 دت" },
    { "room": "غرفة رباعية", "price": "3000 دت" }
  ]
}
```

- `paragraphs` → فقرات نصية عادية
- `list` → قائمة نقاط. النقطة التي **لا** تبدأ بإيموجي تأخذ علامة ✓ خضراء تلقائيا
- `prices` → جدول أسعار الغرف بعمودين

#### `dates` — تواريخ الإقلاع

```jsonc
{
  "id": "28-septembre",         // يظهر في الرابط
  "date": "2026-09-28",         // للترتيب فقط (YYYY-MM-DD)
  "label": "28 سبتمبر",         // التاريخ كما يظهر للزائر
  "name": "عمرة 28 سبتمبر",     // الاسم في مسار التصفح وعنوان الصفحة
  "seats": "باقي 10 أماكن فقط"  // اختياري — احذفه إذا لم ترد إظهاره
}
```

لإضافة تاريخ جديد يكفي إضافة سطر في `dates`، وتنشأ صفحة العرض تلقائيا.

## الصور

- `public/images/annaba.jpeg` · `tebessa.jpeg` · `oued-souf.jpeg` — صور العروض الحقيقية
- `public/images/hero.svg` — **صورة مؤقتة** لهيرو الصفحة الرئيسية، استبدلها بصورة حقيقية
  (عرضية، حوالي 1600×900) وغيّر `heroImage` في `site.json`

الصور الثلاثة حجمها حوالي 2 ميغابايت للواحدة. يُنصح بضغطها لتسريع الموقع.

## الألوان

ثلاثة ألوان فقط، معرّفة في أعلى `src/index.css`:

```css
--color-brand: #0b6e4f;   /* الأخضر الأساسي */
--color-sand:  #f6f4ef;   /* خلفية الموقع */
--color-ink:   #1c1c1c;   /* النصوص والفوتر والهيرو */
```
